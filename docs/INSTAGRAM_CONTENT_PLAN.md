## 0. Before you film anything

### Page setup

| Field | Suggestion |
|---|---|
| Handle | `@echo.on.mac` / `@askdeepakai` (keep one, cross-link the other) |
| Name field | `Echo — the Mac that listens` (the name field is searchable; put the keyword in it) |
| Bio | `I built a JARVIS for my Mac.` / `Voice → it sees your screen, clicks, types, remembers.` / `143 tools. macOS. Built by Deepak 🇮🇳` |
| Link | GitHub repo or a waitlist form. A waitlist beats a repo link for a non-dev audience. |
| Highlights | `Demos` · `Build log` · `FAQ` · `Fails` |
| Profile pic | The reactor core (`assets/reactor-jarvis-core.png`) on black — it reads at 40px |

### The three pillars (rotate them)

1. **WOW** (55%) — one command, one impossible-looking result. This is what gets shared.
2. **BUILD** (30%) — how it works, what broke, why you made a choice. This is what earns followers who stay.
3. **YOU** (15%) — face, story, opinions on AI. This is what turns followers into fans.

### Production rules that matter more than any single idea

- **Hook in 1.5 seconds.** First frame = result or conflict, never a logo, never "hey guys".
- **Screen record at 60fps.** `⌘⇧5`, record the display, not a window — the HUD floats.
- **Crop to 9:16 around the HUD**, not the whole 16:9 desktop. Zoom in. Tiny text kills reels.
- **Keep Echo's real voice in the mix.** The Piper/Gemini voice answering out loud *is* the product. Duck the music to ~20% under it.
- **Caption everything.** 85% watch muted. Burn captions in — don't rely on IG auto-captions.
- **No cuts in the money shot.** When Echo clicks through an app by itself, that must be one unbroken take or people call it fake.
- **Show the HUD state changes** (listening → thinking → speaking). The colour shift is free visual interest.
- **Length:** 7–15s for WOW, 20–40s for BUILD, up to 60s for story. Never pad.
- **Post the same reel as a carousel** a week later with stills + text. Different reach pool, zero extra shooting.

### Audio note (read this once)

Trending audio changes weekly and outranks any fixed list. The rule:
**open Reels → tap the ↗ arrow on any sound with under 20k uses that's trending up → save it.**
Below I name a *type* plus an evergreen fallback that always works for this aesthetic:

- **Tension build** → Hans Zimmer *Time*, *Cornfield Chase*, Oppenheimer *Can You Hear the Music*
- **Menace / flex** → phonk, Ludwig Göransson *Tenet*, dark UK drill instrumental
- **Clean tech demo** → lo-fi minimal, or no music at all (just Echo's voice + key clicks)
- **Funny / relatable** → whatever the current comedy sound is; these date fastest, use within 5 days

### Prompt legend

Each idea gives two kinds of prompt:

- **🎙️ SAY** — the exact words you speak to Echo on camera.
- **🎨 COVER** — an image-gen prompt for the reel cover / carousel art (Midjourney, Imagen, Flux, Firefly — all fine).

## 3. It asked permission before deleting my files

**WOW + BUILD · 18s · easy · ⭐ the trust post**

> fear everyone has about AI agents.

**Hook frame:** `I told my AI to delete everything. On purpose.`

**Shot list**

2. You give the command. HUD goes *thinking*. (3s)
3. **The money frame:** Echo stops and asks out loud for confirmation. Freeze here 1.5s with a red arrow drawn on. (4s)
4. You say *"no."* Nothing happens. Files still there. (4s)
5. Text card: `it can't. unless I say yes.`

**🎙️ SAY:** *"Echo, delete everything in my Downloads folder."* → then *"No. Cancel that."*

**On-screen text beats**
- `0s` I told it to delete everything
- `5s` it stopped
- `8s` ⚠️ it's asking me out loud
- `12s` "no"
- `15s` reading = free. deleting = it asks. every time.

**VO:** *"Every single action gets rated before it runs. Reading the screen is free. Clicking gets logged. Deleting, sending, buying — it stops and asks, out loud, and waits."*

**Audio:** tense minimal, or no music with a heartbeat SFX under the pause.

**Caption:**
> The scariest thing about AI agents is that they *do* things.
> So Echo rates every action before it runs — by what it can *do*, not what it's called. `rm`, `unlink`, a script that deletes: all the same rating.
> Low = runs. Medium = runs and gets logged. High = it stops, asks out loud, and waits for "yes".
> And if it does something dumb anyway: "undo that".
> Would you trust it? Honest answers only 👇

**Hashtags:** `#aisafety #aiagent #macos #buildinpublic #softwareengineering #techsafety #artificialintelligence #devlife #systemdesign`

# Caption formula

```
[One line that restates the hook as a claim]
[Two or three lines of the real mechanism — specific, technical, honest]
[One line of limitation or opinion — this is what makes it credible]
[A question that is genuinely easy to answer] 👇
```

Never open a caption with "In this video". Never write a caption that just describes the
video — the video already did that. The caption's job is the *mechanism* and the *question*.

# Things to never post

- The repo without context — it's not open source, and a link with no story converts nothing.
- A `.env`, a key, the control panel's API key pane, or any frame with `~/.jarvis/keys.env` visible. **Check every single frame for this before posting.**
- Your real inbox, messages, calendar or files. Set up a clean demo account and use it.
- A demo with hidden cuts in the autonomous section. One person will notice, and that's the comment everyone reads.
- Someone else's face, screen or message thread without asking them.
